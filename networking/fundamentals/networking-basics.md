# Computer Networking Fundamentals

## Overview

Computer networking is the interconnection of computing devices to enable communication and the sharing of data, resources, and services.

During my SIWES training, networking was introduced as a foundation for understanding how systems communicate and how network infrastructure can be protected from security threats.

## What I Learned

The introductory networking sessions covered:

- Definition and purpose of computer networks
- Types of computer networks
- Network communication between devices
- Network components and devices
- The role of networking in cybersecurity
- Basic network architectures
- Data transmission and communication

## Types of Networks

Some common network classifications include:

- **LAN (Local Area Network):** A network covering a relatively small geographical area such as an office, laboratory, or building.
- **WAN (Wide Area Network):** A network that connects devices or smaller networks across large geographical areas.
- **MAN (Metropolitan Area Network):** A network designed to cover a city or metropolitan area.

## Networking and Cybersecurity

Networking knowledge is important in cybersecurity because security professionals need to understand how data moves across networks before they can effectively identify, prevent, or investigate attacks.

Understanding network communication provides the foundation for studying areas such as:

- Network security
- Traffic analysis
- Access control
- Intrusion detection
- Network monitoring
- Incident response

## Practical Application

The networking concepts introduced during SIWES were later applied through practical exercises using Cisco Packet Tracer, including device connections, DHCP configuration, routing, subnetting, VLANs, and access control.

## Key Takeaway

Networking provides the foundation upon which many cybersecurity concepts are built. Understanding how devices communicate makes it easier to understand how communication can be monitored, controlled, attacked, and secured.
